# Security

QRDurian runs entirely in the browser. Designs never leave the device; share links
carry the design in the URL hash, which browsers do not send to servers. There are no
accounts and no uploads. qrdurian.com's trace worker sees only origin checks and
counts, never a design.

Report anything that breaks that to danial.alias1@gmail.com. Expect a reply within a
week and credit in the fix if you want it. Please do not file a public issue for a
problem that affects visitors before it is fixed.
